# Chill Campus.ai · student preview

This is a static preview of the Chill Campus.ai study companion. It is shared so classmates can try the interface and send feedback to the project owner.

## Please know before trying it

- Sample syllabus and profile content are examples. Add your own topics to explore the tracker.
- Data is saved in your own browser only. It is not visible to the project owner or other students.
- Sign-in, college verification, AI-generated answers, PDF upload, and shared class resources are not connected yet.
- Please do not enter passwords, student ID numbers, or other sensitive information.

## Feedback to share

1. What did you try first?
2. What was confusing or did not work as you expected?
3. Which feature would make you come back to use it?
4. What should be improved before other students use it?
